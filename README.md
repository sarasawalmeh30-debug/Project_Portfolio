# Personal Portfolio Website

This project is a personal portfolio website designed to showcase my skills, experience, qualifications, projects, and references.

The website provides a simple and organized interface that allows visitors to learn more about me and explore my work.

## Technologies Used

- HTML
- CSS
- Bootstrap
- Font Awesome

## Features

- Responsive design for different screen sizes
- Navigation bar
- About Me section
- Experience section
- Qualifications section
- Skills section
- Projects section
- References section
- Footer with contact and social media icons

## Description

I built this portfolio website using HTML and CSS, with Bootstrap and Font Awesome to improve the design and user interface. I also used CSS Media Queries to make the website responsive and suitable for mobile devices, tablets, and desktop screens.

The main goal of this project is to present my personal information, technical skills, experience, and projects in a clear and professional way.
